# Демо в браузере

<a class="md-button md-button--primary" href="../../demo/">Открыть интерактивное демо</a>

Демо собирается из настоящих Vue-компонентов, стилей, переводов и общего хранилища черновика этого репозитория. Подменяется только реализация API и маршрутизация для статического хостинга. Это отдельная сборка, а не второй интерфейс, который приходится поддерживать вручную.

Попробуйте изменить группу, посмотреть соединение, предпросмотр примера пресета, выбрать политику клиента, применить/отменить изменения или запустить синтетическую диагностику. Язык и тема переключаются в верхней панели.

- В **Журнал → Аудит** есть синтетические примеры восстановления от хука netfilter и от таймера сторожа, неудачной повторной проверки и старой записи без источника. В столбце «Кто» сохраняется автор события для фильтрации, а под ним указан источник восстановления; раскройте запись, чтобы увидеть правило, код завершения и исходную ошибку. Время проверки и восстановления смоделировано и не является замером простоя. Примеры не вызывают настоящих хуков и не меняют firewall.
- Конфигурация хранится в памяти страницы и сбрасывается при перезагрузке.
- Демо не обращается к роутеру или прокси-серверу, не выполняет DNS-запросы, не скачивает фильтры и не проверяет сеть.
- Не вводите настоящие реквизиты: используйте примеры.
- Монитор показывает синтетический трафик и обновляется каждые три секунды. В журнале маршрутизации появляются новые события, работают пауза, фильтры и загрузка предыдущих записей. Кнопка «Применить» добавляет запись в аудит. В каталоге один пример пресета.
- На **Обзоре** видны синтетические показатели CPU и памяти роутера и процесса KeenProxy. В **Настройках → Обновления** можно установить пример версии, откатиться или сохранить время автообновления. Чтобы увидеть обновление по расписанию, выберите следующую минуту на часах демо (UTC) и оставьте раздел открытым. Демо не скачивает релизы и не перезапускает службы.
- **Диагностика → Скачать отчёт** выгружает результаты синтетических проверок. Чтобы собрать журналы и применённые настройки в ZIP, откройте [архив для диагностики](troubleshooting.md#download-the-diagnostic-zip) в панели роутера.
- Импорт YAML недоступен. Экспорт синтетический, в JSON, совместимом с YAML 1.2; это не формат рабочей резервной копии.

Обычная сборка продолжает использовать HTTP API с аутентификацией. В [инструкции сборки](development.md) описано создание обоих вариантов.

# Начало работы

## Перед установкой

Потребуются совместимый роутер с Entware, SSH-доступ, свободная память и место на накопителе, а также способ восстановления. Уточните архитектуру процессора и возможности перехвата трафика для вашей конфигурации. ARM64 и MIPS little-endian — разные файлы сборки. Не выбирайте бинарник только по торговому названию роутера.

Сделайте резервную копию и сохраните SSH/локальный доступ. Начните с синтетического примера, заменяя параметры соединений своими только в приватном окружении. Адреса и ключи из демо не являются рабочими реквизитами VPN.

## Общий порядок установки

1. Получите подходящий бинарник KeenProxy и установщик из проверенного выпуска. Сравните файлы с его `SHA256SUMS`.
2. Скопируйте файлы на роутер и изучите параметры установщика.
3. Установите бинарник со своей конфигурацией. Установщик сохраняет существующую конфигурацию; он не настраивает автозапуск и не запускает/перезапускает службы.
4. Запустите демон через проверенный механизм служб вашей системы и откройте адрес управления из `api.listen`.
5. Войдите с настроенным токеном, если ваш адрес не принадлежит явно доверенной сети.

Исполняемые инструкции установки находятся в корневом [README на GitHub](https://github.com/atrevido/keen-proxy#configuration-and-router-installation). Эта начальная версия руководства намеренно не задаёт команды служб для конкретной прошивки.

## Первая настройка

Следуйте [руководству пользователя](user-guide.md): проверьте соединение, добавьте группу доменов, выберите политику сети/клиента, примените конфигурацию, затем проверьте результат через Диагностику и Журнал. Начните с нескольких доменов и одного тестового устройства.

## Обновление и восстановление

Перед обновлением сохраните конфигурацию и старый бинарник. Прочитайте сведения о совместимости и миграции в выпуске. В Настройках можно открыть предыдущую конфигурацию как черновик; для её применения всё равно требуется **Применить**. Успешная HTTP-проверка не означает, что весь HTTPS-трафик работает.

# Presets, DNS, filters, and YAML
- Bundled presets use domains and optional prefixes. SHA-256 of routing content provides an internal revision independently of display metadata. Group.Preset.Version compares revisions. Three-way updates preserve user additions and exclusions, including entries that temporarily disappear upstream. Updates are opt-in and travel with app releases.
- disabled groups are excluded from compilation, DomainNames/matcher/cache snapshots. Groups/DomainEntries never preview DNS for changed/disabled managed presets. Apply cancels DomainGeneration and old service queries.
- Empty model.DNS.Route = legacy direct upstream + system fallback; direct = explicit without system fallback; connection + Connection ID, Failure strict/direct. connection supports only DoH/DoT. Named upstreams in explicit modes require Bootstrap host→IP maps, preserving TLS hostname. strict forbids direct in chains; container/unknown raw outbound types are rejected for DNS to avoid hidden direct traffic. dnsDial uses sing-box outbound/selector and rejects selected direct: direct fallback is a separate dnsfront leg with audit/status events. CheckDNS queries actual example.com A; demo explicitly uses no network. REFUSED/SERVFAIL never silently switch provider.
- dnsfront transport.go uses separate HTTP2 pools for primary/direct-fallback; lifetime canceled on Close, normal TLS root verification. DoT cancellation captures immutable rawConn. Active RefreshDomains follows the same routing policy (formerly direct resolver).
- Optional DNS BlockEncrypted IPv4 port853 guard: separate KEENPROXY_DNS_GUARD INPUT/FORWARD chain; conntrack original port catches REDIRECT. Own OUTPUT remains allowed. FirefoxCanary NXDOMAIN. DoH443/IPv6 bypass prevention is not promised.
- internal/filterlist: compact sorted suffix matcher supporting plain/hosts/||domain^/@@||domain^. Cosmetic rules rejected, never converted to DNS blocks. Limits 8MiB/200k per source/300k total including snapshot loads; sequential refresh, atomic0600 snapshots, last-good. Disabled lists unload from RAM but retain snapshots. Hourly checks trigger daily updates only for enabled+opt-in lists; manual update API. Manual block groups > user exceptions > lists; direct groups do not override blocks. Exceptions via Filters/Journal, DNS counter on Monitor. No government/RKN lists.
- YAML schema_version1; missing legacy version→1, strict KnownFields, exactly one document. GET/api/config/yaml full or redacted=1 (profiles and URLs removed; redacted: true forbids restore); POST/api/config/import validates into draft only; GET/api/config/previous returns previous saved config. daemon.Apply saves .previous0600 before new YAML. API stays JSON; demo stays in memory.
- Authenticated API GET/catalog, GET/features, POST/presets/preview, POST/filters/refresh, POST/dns/check. UI Presets.vue, Filters.vue, DNSSettings.vue/YAMLSettings.vue. store.setDraft normalizes null arrays after API/import. Custom IDs use crypto.getRandomValues on HTTP LAN.
- DNSSettings.vue uses the embedded resolver catalog for primary and secondary selection. Catalog selections preserve existing bootstrap pins. In `web/src/store.ts`, Apply uses `dnsPairIncomplete` to require two non-empty, distinct priority slots whenever the full upstream list differs from the saved configuration.
